# 安卓离线试验版

运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，得到 `area-estimator-offline-trial.apk`。它把网页、手部模型和 WebAssembly 一起打包，运行时不访问 GitHub Pages。把 APK 复制到安卓手机本地后安装即可；首次打开也不需要网络。

最低 Android 10。首页“拍一张”调用系统相机，“从相册选择”调用系统文档选择器；网页摄像头预览保留作备用。相机拍出的照片放在系统图片目录的“面积估测器”子目录。

模拟器断网测试已覆盖首页、系统相册回传照片、系统相机拍照回传，以及加载手部模型完成一张实拍照的轮廓和格数计算。安卓真机与不同系统 WebView 版本仍需测试。

这是使用本机调试证书签名的试验 APK。正式分发前需要建立并妥善保管发布证书；换证书升级需要先卸载试验版。面积识别算法与网页 v12.6 相同，精度边界也相同。首页说明统一收在右上角问号中。
